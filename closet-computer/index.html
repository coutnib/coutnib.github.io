Closet Computer

A digital wardrobe that runs privately on your own computer.

Heads up: this one can't run on GitHub Pages

Closet Computer needs a small Python server (background removal, saved photos, your closet database). GitHub Pages only serves static files, so this page is just the front door. Run the app locally using the steps below.

What it does

  • Upload clothes from photos; backgrounds are removed on your machine, no API key needed.
  • Sorted and searchable by category, color and tag, with favorites.
  • Dress me: flip through rows, lock the ones you like, and shuffle the rest.
  • Lookbook: save outfits as flat-lay collages.
  • Try it on me: preview outfits on your own photo with any image model you plug in.

Run it

You need Python 3.10–3.13 (python.org).

  1. Download or clone this repo and open the closet-computer folder.
  2. Mac / Linux: 
    ./run.sh
    Windows: double-click run.bat.
  3. The first run installs dependencies and downloads the background-removal model (about 180 MB, once). Then open http://127.0.0.1:8765.

To photograph clothes from your phone on the same Wi-Fi, run ./run.sh --lan and open the address it prints. Only do this on a network you trust.

Your data stays with you

Everything lives in the data/ folder on your computer (it's git-ignored, so it won't be pushed to GitHub). API keys for try-on models are stored there too, or can be set as environment variables.

See README.md in this folder for try-on model setup and the plugin guide.
